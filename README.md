# 🚚 ControlKM - Gestión de Flotilla Empresarial

![Status](https://img.shields.io/badge/Status-En_Desarrollo-success) ![Next.js](https://img.shields.io/badge/Next.js-14-black) ![TypeScript](https://img.shields.io/badge/TypeScript-Blue) ![Prisma](https://img.shields.io/badge/Prisma-ORM-1B222D)

**ControlKM** es una plataforma de software integral diseñada específicamente para administrar, controlar y analizar todos los recursos móviles de la empresa, optimizando los costos operativos y la logística.

Este repositorio contiene la Plataforma Web Administrativa, la cual sirve como panel de control central para la gestión de vehículos, operadores, mantenimientos y gastos operativos.

## ✨ Características Principales

* 📊 **Panel de Control (Dashboard):** Analíticas en tiempo real del flujo de gastos, kilómetros recorridos, alertas de mantenimiento y estatus de los vehículos.
* 🚗 **Gestión de Vehículos:** Registro detallado del padrón vehicular, asignación de unidades a conductores, pólizas de seguro y control de telemetría.
* 👥 **Directorio de Empleados:** Base de datos robusta para el control de operadores, vigencia de licencias y asignación de activos corporativos.
* 🔧 **Módulo de Mantenimientos:** Historial clínico de las unidades, programación de servicios preventivos y correctivos con autorización de presupuestos.
* ⛽ **Control de Combustible y Viáticos:** Registro detallado de recargas de gasolina, peajes (casetas) y comidas, previniendo fugas de capital.
* 🛡️ **Catálogo de Seguros:** Módulo para la prevención de riesgos y alertas automáticas de vencimiento de pólizas de la flotilla.

## 🛠️ Stack Tecnológico

* **Framework Frontend / Backend:** Next.js (App Router, Server Actions)
* **Lenguaje:** TypeScript, JavaScript
* **Base de Datos:** SQLite (vía Prisma ORM)
* **Estilos y Diseño:** Tailwind CSS, Shadcn UI (Componentes Enterprise)
* **Librerías Adicionales:** 
  * `dnd-kit` (Drag & Drop interactivo para organización visual)
  * `Recharts` (Gráficas, reportes y KPIs analíticos)
  * `Sonner` (Alertas interactivas y notificaciones)
  * `Lucide React` (Iconografía)
